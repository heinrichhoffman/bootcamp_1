# 💻 Projeto Pessoal:

## 📝 Descrição
Este é um projeto desenvolvido de forma independente com o intuito de resolver um problema prático e aprofundar meus conhecimentos lógicos e de programação. A aplicação foca em automatizar tarefas e manipular dados de forma eficiente.

## 🚀 Motivação
Como busco aperfeiçoamento constante, especialmente em Inteligência Artificial e manipulação de dados, decidi criar esta solução para testar minhas habilidades fora do ambiente acadêmico tradicional, simulando um desafio real do mercado de trabalho.

* Lógica de Programação
