#  Portfólio Acadêmico e Profissional

Bem-vindo ao meu repositório central de projetos! Este espaço foi criado para armazenar, versionar e organizar meus projetos acadêmicos e pessoais, com o objetivo de compor um perfil profissional estruturado.

## 📁 Estrutura do Repositório

O repositório está organizado nas seguintes seções:

* **`/projetos-academicos`**: Trabalhos e projetos desenvolvidos ao longo do curso.
* **`/projetos-pessoais`**: Iniciativas próprias, testes e desenvolvimento extracurricular.
* **`/documentacao`**: Arquivos de apoio, slides e materiais complementares da página web.

## 🛠️ Ferramentas e Tecnologias

* **Git:** Para o versionamento local dos projetos (Versão 1.0).
* **GitHub:** Para hospedagem, colaboração e compartilhamento do código.
* **GitHub Pages:** Para a criação e publicação da página web estática.
* **HTML/CSS:** Estrutura base da página web.
